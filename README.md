## 🏗 Архитектура проекта (Bounded Contexts)
Приложение декомпозировано на 3 изолированных контекста с персистентным хранением в реляционной СУБД **SQLite (`SQLModel`)**:
1. **Контекст 1: Каталог и склад (`/products`)** — номенклатура товаров, контроль и атомарное резервирование остатков.
2. **Контекст 2: Заказы и корзина (`/orders`)** — сквозное оформление заказов со списанием остатков склада и фиксацией цены покупки (`price_at_purchase`).
3. **Контекст 3: Клиенты и авторизация (`/users`)** — регистрация и аутентификация покупателей с криптографическим хэшированием паролей (**SHA-256**).

---

## 🌐 Веб-интерфейсы системы
* `http://127.0.0.1:8080/shop` — **Клиентская витрина интернет-магазина «UUST Store»** (шаблонизатор **Jinja2**).
* `http://127.0.0.1:8080/admin` — **Панель мониторинга таблиц СУБД SQLite**.
* `http://127.0.0.1:8080/docs` — **Интерактивная документация OpenAPI (Swagger UI)**.

## 🚀 Запуск проекта

### Вариант 1: В контейнере Docker (Рекомендуется)
```bash
docker compose up --build -d
```




### Вариант 2: Локальный запуск
```bash
pip install -r requirements.txt
python main.py
```
